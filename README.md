
# Pizza-Sales-Revenue-Analysis
Analyzed 48K+ pizza sales records using SQL, Excel, Power BI, DAX, and Power Query to evaluate sales performance, revenue trends, order patterns, product performance, and category-level insights. Developed an interactive Power BI dashboard with KPI cards, slicers, trend analysis, and Top/Bottom product analysis to present actionable business insights

## Objective
Analyze pizza sales data to understand revenue, orders, quantity sold, product performance, pizza categories, sizes, and sales trends. Use SQL for structured data analysis and Power BI for interactive visualization and business reporting.

### Skills Learned

- SQL querying, filtering, aggregation, grouping, and business analysis
- Data cleaning and preparation using Power Query
- Power BI dashboard development and data visualization
- DAX measures for KPI calculations and business metrics
- Sales, revenue, order, category, size, and product-level analysis
- Top/Bottom product performance analysis
- Interactive dashboard design and data storytelling
- Converting raw sales data into meaningful business insights

### Tools Used

- **Python** Data cleaning, preprocessing, exploratory data analysis (EDA), and identifying sales trends.
- **SQL** Data querying, filtering, aggregation, and business analysis.
- **Excel** Data preparation, validation, calculations, and initial analysis.
- **Power Query** Data transformation, cleaning, and preparation.
- **Power BI** Interactive dashboard development, data visualization, KPI reporting, and sales analysis
- **DAX** Creating calculated measures and business KPIs such as Total Revenue, Total Orders, Total Pizza Sold, Average Order Value, and Average Pizza per Order.

## Steps

Below are the key steps taken in the VAPT process:

### 1. Data Collection & Understanding
Reviewed the pizza sales dataset and understood order, product, category, size, quantity, price, and date fields.


### 2. Data Cleaning & Preparation
Used Python and Power Query to clean, transform, validate, and prepare the dataset.


### 3. Exploratory Data Analysis
Used Python to explore sales patterns, product performance, order behavior, and category trends.


### 4. SQL Analysis
Used SQL for filtering, grouping, aggregation, and extracting business insights.

### 5. DAX KPI Development
Created measures for Total Revenue, Total Orders, Total Pizza Sold, Average Order Value, and Average Pizza per Order.


## 6. Power BI Dashboard
Built an interactive dashboard with KPI cards, slicers, charts, sales trends, and Top/Bottom seller analysis.

## 7.  Business Insights
Interpreted the analysis to identify important revenue, product, category, and order trends.
